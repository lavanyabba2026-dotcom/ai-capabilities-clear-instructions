# Lesson 3: Test It, Check It, Own the Decision

## Easy

### 1. What makes a short-versus-detailed instruction test fair?

A fair test uses the same task and the same AI assistant with two different instructions: one short and one detailed. We should compare both actual answers before deciding which one is better. We should not assume that a longer instruction will always give a better result.

### 2. What is a consequential claim?

A consequential claim is information that could affect someone's decisions or actions. For example, an exam date shared in a class group or a ticket price printed on a public fest poster is consequential because people may rely on that information. Such claims should be checked before they are shared or used.

### 3. Why should a student check a confident AI answer before using it publicly?

An AI answer can sound confident and still be incorrect. If a student shares unverified information publicly, it could mislead others or cause confusion. Therefore, the student should check the information against a reliable source, such as an official college notice, before sharing it.

## Intermediate

### 4. A short instruction gives a correct but general fest reminder. A detailed instruction includes the correct time, venue, and volunteer reporting time. Which answer better serves the fest committee? Explain why.

The detailed instruction serves the fest committee better because it includes all the important information, such as the time, venue, and volunteer reporting time. The short instruction is correct, but it is too general for the committee's needs. The detailed reminder is more useful because the committee members know exactly when and where to report.

### 5. An AI writes a college exam date in a class-group message, but gives no source. What should the student do before forwarding it?

The student should verify the exam date using the official college notice or confirm it with the college administration. The student should not forward the message just because the AI sounds confident. Once the date is confirmed by a reliable source, the student can safely share the correct information with the class group.

## Hard

### 6. Write one short instruction and one detailed instruction for the same real student task. State what must stay the same so the comparison is fair.

**Task:** Writing a reminder for classmates about submitting an assignment.

**Short instruction:**

Write a reminder for classmates to submit their assignment tomorrow.

**Detailed instruction:**

Write a short reminder for my college class WhatsApp group asking everyone to submit their assignment by 4 PM tomorrow. Keep the message friendly, clear, and under 30 words.

**What must stay the same?**

The task and the AI assistant must stay the same. I will compare both answers based on whether they meet the actual task requirements. I should read both responses before deciding which one is more useful. I should not automatically choose the longer answer.

### 7. Change only one part of your detailed instruction, such as the audience or limit. Write what you expect to change in the new answer and what you will check after it runs.

**Original instruction:**

Write a short reminder for my college class WhatsApp group asking everyone to submit their assignment by 4 PM tomorrow. Keep the message friendly, clear, and under 30 words.

**Changed instruction:**

Write a short reminder for my college professor asking for confirmation of the assignment submission deadline. Keep the message polite, clear, and under 30 words.

**Expected change:**

I expect the answer to become more formal and respectful because the audience has changed from classmates to a professor.

**What I will check:**

I will check whether the new message uses a polite tone, stays under 30 words, and clearly asks the professor to confirm the deadline. I will also make sure the message does not include any unsupported information.
